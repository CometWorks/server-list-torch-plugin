# CometWorks Server List

Publish your Space Engineers community on **[se-servers.net](https://se-servers.net)** directly from Torch.

- Live player counts and simulation speed for standalone Torch servers.
- Automatic **Nexus V3** detection and **online / total sectors** status, scoped to the current cluster. Hidden sectors remain private.
- Current Steam administrators can edit their community page after signing in with Steam.
- Sharing is opt-in. No logs, player identities, private endpoints or world data are uploaded.

Configure **Share server listing**, your **public join host** and **public join port** in the Torch plugin tab. For Nexus, install and enable this publisher on **one server per cluster**, normally the lobby, and use the public lobby join address. Keep sharing disabled on the other sectors to avoid duplicate community listings.

Source, setup, privacy and build instructions: [CometWorks/server-list-torch-plugin](https://github.com/CometWorks/server-list-torch-plugin).

MIT licensed. Requires Torch and .NET Framework 4.8. Nexus V3 integration is optional; Nexus V2 is not supported.
