It supplies RSA-PSS signatures, RSA-OAEP SHA256 and portable PEM/SPKI encoding
for .NET Framework 4.8. Torch supplies Newtonsoft.Json, protobuf-net, Torch
and Space Engineers runtime assemblies; these are not bundled in this plugin.

The Nexus adapter implements the public Nexus V3 Mod API wire contract:
https://se-nexus.net/docs/mod-api
https://github.com/SE-Nexus/NexusScripts/blob/master/ModAPI/NexusAPI.cs
No Nexus implementation, binary or source is redistributed.
